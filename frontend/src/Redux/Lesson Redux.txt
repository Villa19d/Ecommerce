

# 🛒 Flujo de Redux en E-Commerce (Django + React)
## 🔄 Flujo General de Redux
Componente React → Dispara una acción (ej: login())
Action → Hace petición a Django API → Despacha resultado al reducer
Reducer → Actualiza el estado global según la acción
Componente → Se re-renderiza con los nuevos datos (usa useSelector)

¿Qué hace?
  🔹dispatch: Función de Redux para enviar acciones al store.
  🔹type: Tipo de acción (usado en el reducer para saber cómo actualizar el estado).
  🔹payload: Datos asociados a la acción (en este caso, el mensaje y tipo de alerta).
