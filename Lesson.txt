🔄 Cómo se comunican ambos lados
    ⚫Flujo:
    🔹React hace peticiones HTTP a los endpoints de Django (ej: /api/product/)
    🔹Django procesa la solicitud (views.py) y devuelve JSON (serializers.py)
    🔹React recibe los datos y actualiza la interfaz

    ⚫Ejemplo concreto (Productos):

    Frontend (Shop.jsx) → GET /api/product/ → Django (product/views.py) → 
    Product.objects.all() → product/serializers.py → JSON → React lo muestra

    ⚫Autenticación:
    🔹React envía credenciales a /auth/login/
    🔹Django (Djoser) verifica y devuelve JWT token
    🔹React almacena el token y lo envía en headers para requests autenticados

    TailwindCSS (frontend/tailwind.config.js):  Configuración del sistema de estilos
